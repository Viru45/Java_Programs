# Java Programming Practice

A dedicated space for my journey through the Java ecosystem. This repository serves as a digital notebook for practicing syntax, logic, and core software engineering principles.

## 🚀 Overview
The goal of this project is to build a solid foundation in Java. It tracks my progress from "Hello World" to more complex concepts like Object-Oriented Programming (OOP) and Data Structures.

## 🛠️ Tech Stack
* **Language:** Java 17+
* **IDE:** [e.g., IntelliJ IDEA / VS Code / Eclipse]
* **Build Tool:** [e.g., Maven / None]

## 📂 Project Structure
Each directory focuses on a specific area of Java development:
* `basics/`: Variables, loops, and conditional logic.
* `oop/`: Classes, inheritance, interfaces, and polymorphism.
* `collections/`: Lists, Sets, and Maps.
* `exceptions/`: Error handling and custom exceptions.
* `projects/`: Small console-based applications (e.g., Calculator, Student Management System).

## 📝 Key Concepts Practiced
- [x] **Basics:** Data types, operators, and control flow.
